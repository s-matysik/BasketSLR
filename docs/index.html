BasketSLR 🧺 Association rules of author keywords for SLR thematic mapping

BasketSLR is a compact Python framework that formalises association rule mining (ARM, Apriori) of author keywords as a reproducible, complementary method for thematic mapping in systematic literature reviews (SLR). Each publication is a transaction; its author keywords form the basket. ARM adds three capabilities absent from symmetric co-occurrence tools such as VOSviewer or Bibliometrix:

  • Directional conditional probabilities (confidence: A → B ≠ B → A)
  • Multi-item thematic clusters (frequent itemsets of size k ≥ 3)
  • Quantified interestingness thresholds (support, confidence, lift)

Note: VOSviewer's association-strength normalisation is mathematically equivalent to ARM's lift – BasketSLR exposes the two missing dimensions.

4  Parameters

ParameterSymbolDefaultNotes
min_supportσ0.005corpus-dependent; "auto" runs iterative halving (start 0.05, halve until ≥ 10 keyword pairs pass)
min_confidenceγ0.3widely used ARM default

Rules of thumb for σ: small corpora (N < 100): 0.05–0.10; medium (100–1,000): 0.005–0.02; large (> 1,000): 0.001–0.005.

4.1 Interpretive-bound warnings

auto_min_support() emits a UserWarning when the calibrated threshold leaves a rule resting on very few publications, or when the corpus itself is small:

ConditionConstantMeaning
σ·n < 3MIN_ABS_SUPPORT_HINTa surviving rule can rest on one or two co-occurring publications; high lift then signals rarity, not an established link
n < 100MIN_CORPUS_HINTrule sets from corpora this small should be read as exploratory

Both bounds come from the cross-domain validation. No floor is enforced – rare co-occurrences may indicate emerging themes, so the caller keeps control of the trade-off. Suppress the warnings with the standard library if they are expected:

import warnings
with warnings.catch_warnings():
    warnings.simplefilter("ignore", UserWarning)
    sigma = b.auto_min_support(transactions)

σ·n is the effective absolute threshold: the minimum number of co-occurring publications a pattern must reach. Because a fixed σ implies a different σ·n at every corpus size, the same σ behaves differently across corpora – which is what the calibration heuristic exists to absorb.

5  Python API example

import basketslr as b

df  = b.read_csv("scopus.csv")
tr  = b.extract_transactions(df)          # publications -> keyword baskets
print(b.corpus_stats(tr))

sigma = b.auto_min_support(tr)            # optional calibration
freq, rules = b.mine(tr, min_support=sigma, min_confidence=0.3)

b.plot_rules_network(rules, top_n=40, path="network.png")
b.full_report(tr, freq, rules, sigma, 0.3, path="arm_report.txt")

7  Reproducible example

The repository ships the CSR corpus (examples/, 597 Scopus records). With σ = 0.005 and γ = 0.3 BasketSLR yields 278 frequent itemsets (151 singletons, 115 pairs, 11 triples, 1 quadruple) and 138 association rules, e.g. {brand equity, brand loyalty} → {brand awareness} with lift = 52.03 – identical on every run.

7.1 Cross-domain validation corpora

additional-validation/ holds six further Scopus corpora spanning management, economics and computer science, each with its source keywords, the complete analytical output of a calibrated run, and a row in summary.csv. They cover a 420-fold range of corpus size.

Case 6 distributes the Author Keywords column only; the full Scopus export is 232 MB. Star share is the fraction of rules whose consequent is the single most frequent keyword – it rises with σ·n, which is why the largest corpora concentrate on one anchor term.

7.3 Tests

The suite covers ingestion and degenerate inputs, mining and the metric identities the method relies on, regression against every value reported in the article, and the end-to-end pipeline including byte-identical reproduction of the shipped outputs:

pip install -e ".[test]"
pytest

Continuous integration runs it on every push and pull request across Python 3.9–3.13 on Linux, plus Python 3.12 on macOS and Windows.
