BasketSLR 🧺 Association rules of author keywords for SLR thematic mapping

BasketSLR is a compact Python framework that formalises association rule mining (ARM, Apriori) of author keywords as a reproducible, complementary method for thematic mapping in systematic literature reviews (SLR). Each publication is a transaction; its author keywords form the basket. ARM adds three capabilities absent from symmetric co-occurrence tools such as VOSviewer or Bibliometrix:

  • Directional conditional probabilities (confidence: A → B ≠ B → A)
  • Multi-item thematic clusters (frequent itemsets of size k ≥ 3)
  • Quantified interestingness thresholds (support, confidence, lift)

Note: VOSviewer's association-strength normalisation is mathematically equivalent to ARM's lift – BasketSLR exposes the two missing dimensions.

4  Parameters

ParameterSymbolDefaultNotes
min_supportσ0.005corpus-dependent; "auto" runs iterative halving (start 0.05, halve until ≥ 10 keyword pairs pass)
min_confidenceγ0.3widely used ARM default
max_lenk4maximum itemset size; None/0 = unlimited

Rules of thumb for σ: small corpora (N < 100): 0.05–0.10; medium (100–1,000): 0.005–0.02; large (> 1,000): 0.001–0.005.

5  Python API example

import basketslr as b

df  = b.read_csv("scopus.csv")
tr  = b.extract_transactions(df)          # publications -> keyword baskets
print(b.corpus_stats(tr))

sigma = b.auto_min_support(tr)            # optional calibration
freq, rules = b.mine(tr, min_support=sigma, min_confidence=0.3)

b.plot_rules_network(rules, top_n=40, path="network.png")
b.full_report(tr, freq, rules, sigma, 0.3, path="arm_report.txt")

7  Reproducible example

The repository ships the CSR corpus (examples/, 597 Scopus records). With σ = 0.005 and γ = 0.3 BasketSLR yields 278 frequent itemsets (151 singletons, 115 pairs, 11 triples, 1 quadruple) and 138 association rules, e.g. {brand equity, brand loyalty} → {brand awareness} with lift = 52.03 – identical on every run.
